# Dodge the Blocks
CMPSC 457 – Computer Graphics Group Project

## Project Description
Dodge the Blocks is a school themed 3D arcade game
built using WebGL, JavaScript, GLSL shaders, and MV.js.

The player moves between three lanes to avoid falling
school related obstacles

## How to Run
Play the prototype in your browser:

https://miakaranikas.github.io/Dodge-the-Blocks/

Alternatively, download the repository as a ZIP,
extract all files, and open index.html in Chrome.

## Controls
- A: Move left
- D: Move right
- Q: Rotate camera left
- E: Rotate camera right

## Current Features (GA2)
- 3D hallway with three lanes
- 3D player cube
- Falling textbook obstacle
- Keyboard controlled player movement
- Movable perspective camera
- Animation using requestAnimationFrame
- Model view transformations

## Planned Features (GA3)
- Student character
- Additional falling school objects
- Collision detection
- Scoring and lives
- Lighting and shading
- Texture mapping
- School hallway decorations
